## Objetivo

Aplicar el ciclo completo de Git: modificar un archivo, verificar los cambios,
agregarlos al área de preparación, confirmarlos y subirlos al repositorio remoto.

## Estructura del proyecto

```
ejercicio-3/
├── README.md     Documentación del proyecto
├── index.html    Página principal
└── style.css     Hoja de estilos
```

## Comandos utilizados

| Comando | Función |
|---------|---------|
| `git status` | Muestra el estado de los archivos |
| `git add` | Agrega los cambios al área de preparación |
| `git commit -m` | Guarda una instantánea en el historial local |
| `git push` | Envía los commits al repositorio remoto |
