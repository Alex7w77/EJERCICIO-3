El ciclo de Git

  1. 1

    Modificar

    El cambio existe solo en el directorio de trabajo.

  2. 2

    git status

    Verifica que Git detecto el cambio. No modifica nada.

  3. 3

    git add

    Mueve el cambio al area de preparacion (staging).

  4. 4

    git commit

    Guarda una instantanea en el historial local.

  5. 5

    git push

    Envia los commits al repositorio remoto en GitHub.

Concepto clave

El commit es local y el push es remoto. Se pueden hacer varios commits sin conexion a internet y subirlos todos juntos con un solo push.
